# Linear Algebra 2 — SUPSI

Python code for the course **Linear Algebra 2** at SUPSI: the Jupyter notebooks used in class, and the Python template you will also find at the tests.

## Contents

- `Chapter 1 - *.ipynb`: the notebooks of Chapter 1 (eigenvalues, eigenvectors and eigenspaces). The notebooks of the next chapters will be added during the course.
- `linear_algebra_exam_template.py`: the Python template available during the tests, in the VS Code environment of Safe Exam Browser.
- `plot2d_utils.py`, `plot3d_utils.py`: small functions to draw axes, lines, planes and vectors, used by the notebooks. Keep them in the same folder as the notebooks.

## Requirements

Python 3 with the packages

```
pip install sympy numpy plotly nbformat ipykernel
```

Open the notebooks with VS Code (with the Jupyter extension) or with Jupyter, and run the cells from top to bottom.
